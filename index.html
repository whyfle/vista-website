vista

Tell Vista what you want. Vista figures out how your Linux system should install it.

curl -fsSL https://raw.githubusercontent.com/whyfle/vista/main/install.sh | sudo bash

Release 1: .rpm / .deb / .pkg.tar.zst · source · MIT

install

one line

curl -fsSL https://raw.githubusercontent.com/whyfle/vista/main/install.sh | sudo bash

Detects your distro, grabs the matching Release 1 binary, verifies sha256.

manual

sudo ./install.sh        # asks once
sudo ./install.sh --yes  # no prompt
./install.sh --dry-run   # preview

Fedora/RHEL/openSUSE → rpm · Debian/Ubuntu → deb · Arch → pkg.tar.zst.

from source

cargo build --release
./target/release/vista sys-info

Rust, single ~3.7 MB binary. No runtime deps.

how it resolves

1. nativeInspects GitHub release assets, scores them: native +100, arch +50, distro +50, stable +25, github +20. Installs the winner via dnf / apt / pacman.
2. flatpakNo native build? Falls back to Flathub (vista install discord → com.discordapp.Discord). Explicit user@repo only diverts on a real name match.
3. honest errorNothing usable → clear error, never a blind install. Tarballs download with a manual-install note, never executed.
securitysha256 verification, arch/format checks, one confirmation prompt (-y to skip), auto-sudo only for the package-manager step. No piped remote scripts, no auto-ran install scripts.
